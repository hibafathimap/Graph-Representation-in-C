# Graph Representation and Traversal in C

## Description

This project implements a small social network using an adjacency matrix and an adjacency list in C.

## Graph Connections

* A-B
* A-C
* B-D
* B-E
* C-F
* E-F

## Features

* Adjacency Matrix
* Adjacency List
* Breadth-First Search (BFS)
* Depth-First Search (DFS)
* Vertex Searching
* Time and Space Complexity Analysis

## Output

**BFS:** A B C D E F

**DFS:** A B D E F C

**Search:** Vertex E found after 5 comparisons in both representations.

## Programming Language

C

## How to Run

Compile the program:

```
gcc graph.c -o graph
```

Run the program:

```
./graph
```
